BULK-DEAL BUYER PERSISTENCE -- FROZEN RULES (stated before any result below was computed)
====================================================================================================
Spec      : docs/superpowers/specs/2026-07-29-bulk-buyer-persistence-design.md
Mode      : FULL VERDICT RUN

Entity    : deterministic normalizer only (uppercase; truncate at a standalone A/C|A\C|A.C|AC
            account marker; & -> AND; punctuation -> space; strip TRAILING tokens from the
            declared list ['LIMITED', 'LTD', 'PRIVATE', 'PVT', 'LLP', 'HUF']), then an EXPLICIT alias
            table (bulk_buyer_aliases.csv, 73 rows) applied AFTER normalization.
            NO fuzzy matching anywhere.
Records   : buyer track records accumulate from 2019-10-01. Outcome of a BUY deal =
            20d NET abnormal return, E+1 open -> E+21 open, vs the EW universe over
            the same span (IC-2). Computable only when the whole window fits in the panel.
Qualify   : at event date t, buyer needs >= 15 prior deals whose outcome windows
            COMPLETED STRICTLY BEFORE t (IC-4), and a trailing hit rate at or above the
            75th percentile of all such qualified buyers, threshold recomputed per ISO
            week from information available at that week's Monday (IC-3, flagged).
Gate      : symbol in panel, TURNOVER_LACS >= 200, adjusted close >= Rs 20,
            evaluated on the DEAL day E -- the last data before the E+1 open fill (IC-1).
Exclusion : entity on BOTH sides of the same symbol-day is dropped from events AND from
            track records (IC-5). One event per (entity, symbol, date) (IC-6).
Costs     : Rs 20,000 notional, 0.2%/side slippage on the fill price, then
            zerodha_charges.calculate_charges(buy_v, sell_v, is_intraday=False)['total']
            (never sum(.values()) -- that double-counts).
Benchmark : EW, daily-rebalanced, OPEN-to-OPEN, gated universe, returns clipped +/-25%,
            FRICTIONLESS (deliberately generous counterfactual).
Test era  : events from 2022-01-01 only. Earlier events feed records ONLY (asserted).
Arms      : TOP-QUARTILE (the one declared test) and CONTROL = all gated BUY events,
            undifferentiated -- a SUPERSET of the top-quartile arm (IC-7).
Verdict   : ALL of --
            C1  top-quartile mean net AR > 0 in BOTH era halves, each with >= 40 events
            C2  pooled cluster-robust t >= +2.0, clustered by ISO WEEK OF THE DEAL
            C3  (top-quartile - control) difference > 0 with cluster t >= +1.5
            C1+C2 pass but C3 fail => "generic bulk-deal drift, buyer identity decorative"
            => FAIL for this spec. Declared test count: 1.
Caveats   : warmup records rest on ~2.3y of deals (thin); entity-resolution errors bias
            TOWARD the null except alias mistakes; the literature puts bulk-deal alpha
            PRE-disclosure, so a null here is the predicted outcome.

Panel: 1682 files (0 unusable), 3057378 EQ stock-days, 3204 symbols, 2019-10-01 -> 2026-07-27
Corp-action adjustment: 312489 stock-day rows scaled, 451 symbols with >=1 valid action.
